# Credit_Card_Fraud_Detection
Machine Learning project for detecting fraudulent credit card transactions using Logistic Regression, Random Forest, and XGBoost.

## Dataset
Kaggle Credit Card Fraud Detection Dataset

## Models Used
- Logistic Regression
- Random Forest
- XGBoost

## Features Engineered
- Log Amount
- Amount to Mean Ratio
- High Amount Flag
- Night Transaction Flag

## Evaluation Metrics
- ROC-AUC
- Precision
- Recall
- F1 Score
- Average Precision

## Visualizations
- Amount Distribution
- Fraud vs Non-Fraud Pie Chart
- Correlation Heatmap
- PR Curve

## Results
Best model: XGBoost
